# AcousticChrono

Браузерный акустический хронограф для пневматики.

**Репо:** https://github.com/DLL-chief/acoustic-chronograph  
**Pages:** Settings → Pages → branch `main` → потом https://dll-chief.github.io/acoustic-chronograph/

## Почему старый «живой» детектор врал

Два глобальных максимума амплитуды часто берут **эхо выстрела**, а не удар в мишень. Без геометрии S1/S2 скорость звука смешивает Δt.

## Формулы

- `c = 331.3 + 0.606 · T`
- `S1 = hypot(Xb, D)`, `S2 = hypot(L − Xb, D)`
- `vp = L / (Δt_meas − (S2 − S1)/c)`
- `E = m v² / 2`

## DSP (сейчас JS TypedArray, контракт как у WASM)

1. Огибающая энергии, не сырой сэмпл.
2. Первый пик = выстрел, затем **мёртвая зона** (эхо).
3. Второй пик ищется в окне вокруг `L/v_expected + (S2−S1)/c`.
4. Ручные маркеры на волне, если авто сбилось.

Настоящий `.wasm` в одном HTML с file:// / Pages без сервера упирается в CORS. Модуль `DSP.find` совместим с заменой на WASM.
