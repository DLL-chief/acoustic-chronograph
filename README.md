# Acoustic Chronograph / Акустический хронограф

Браузерный хронограф для пневматики: скорость считается по времени между двумя звуковыми пиками с микрофона (Веб-Аудио API).

**Репозиторий:** https://github.com/DLL-chief/acoustic-chronograph  
**Живое демо (GitHub Pages после включения):** https://dll-chief.github.io/acoustic-chronograph/

## Как это работает

1. Задаётся база — расстояние между двумя метками на траектории (м).
2. Микрофон фиксирует два коротких пика (пролёт меток или выстрел + удар в цель).
3. `v = d / Δt`, энергия `E = 0.5 * m * v²`.

Точность зависит от акустики, шума, расстояния и латентности браузера. Это учебный/полевой инструмент, а не замена оптическому хронографу.

## Запуск

Откройте `index.html` локально через HTTPS/локальный сервер или включите GitHub Pages:
Settings → Pages → Deploy from branch `main` / root.

Микрофон работает только на HTTPS или `localhost`.
